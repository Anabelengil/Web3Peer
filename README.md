# Web3Peer

Syncs decentralized web data between devices in real time, designed for Web3 developers and researchers.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/Web3Peer.git`
2. `cd Web3Peer`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure Web3Peer, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
